OneApply - MVP Workflow

One click to reach any recruiter

1. Complete User Flow (with Approval Gate)

flowchart TD
    A["User visits recruiter's\nLinkedIn profile"] --> B["Clicks 'Reach Out'\nin Chrome Extension"]
    B --> C["Extension reads visible\nprofile data from DOM"]
    C --> D["Popup: recruiter info,\nJD paste box, resume picker"]
    D --> E["User pastes JD\n& clicks 'Draft'"]
    E --> F["POST /api/outreach/draft"]

    F --> G{"Daily rate limit\n(3/day)?"}
    G -->|Exceeded| H["Error: quota"]
    G -->|OK| CASCADE["Run Email Cascade\n(see diagram 6)"]

    CASCADE -->|Not found| M["Error:\nemail_not_found"]
    CASCADE -->|Found| N["LLM: draft email\n+ pick best resume"]

    N --> O["Create outreach row\nstatus=pending_approval"]
    O --> P["Return draft to\nextension"]
    P --> Q["Popup shows draft:\nsubject + body editable"]

    Q --> R{"User action"}
    R -->|Cancel| S["POST /api/outreach/:id/cancel\nstatus=cancelled"]
    R -->|Approve/Edit + Send| T["POST /api/outreach/:id/approve"]

    T --> U["Gmail API: send email\n(with edits if any)"]
    U --> V["Update outreach:\nstatus=sent, thread_id"]
    V --> W["Extension: success toast\nDashboard: row appears"]

4. Follow-Up Service

Automatically sends follow-up emails if no response after 3 days. Max 3 follow-ups per recruiter, then marks as "no_response".

flowchart TD
    F1["Follow-Up Worker\n(runs every hour)"] --> F2["Query outreach table:\nstatus = 'sent' OR 'followed_up'\nAND last_contact > 3 days ago\nAND follow_up_count < 3"]
    F2 --> F3{"Found outreach\nrecords?"}
    F3 -->|No| F1
    F3 -->|Yes| F4["For each record:"]

    F4 --> F5{"Check Gmail:\nany reply on\nthis thread?"}
    F5 -->|Yes| F6["Update status → 'replied'\nSkip follow-up\nUpdate Google Sheet"]
    F5 -->|No| F7["Generate follow-up\nemail via LLM"]

    F7 --> F8["LLM drafts follow-up\nbased on:\n- Original email\n- Follow-up number (1/2/3)\n- JD context"]
    F8 --> F9["Send follow-up via\nGmail API\n(same thread)"]
    F9 --> F10["Update PostgreSQL:\nfollow_up_count += 1\nlast_followed_up_at = now()\nstatus = 'followed_up'"]
    F10 --> F11["Update Google Sheet:\nStatus, Follow-up Count,\nLast Follow-up Date"]
    F11 --> F12{"follow_up_count\n= 3?"}
    F12 -->|No| F1
    F12 -->|Yes| F13["Update status →\n'no_response'\n(stop following up)"]
    F13 --> F1

    F6 --> F1

6. Email Finder — Cascade (Cache → Pattern+Verify → Apollo)

flowchart TD
    R1["Input: name, company,\nlinkedin_url"] --> R2{"Cache hit in\ncontacts table?"}
    R2 -->|"Yes (deliverable)"| RET["Return email\n[source=cache]"]
    R2 -->|"No"| R3["DomainResolver:\ncompany → domain"]

    R3 --> R4["PatternGenerator:\nfirst.last@d, flast@d,\nfirst@d, ... (~8 formats)"]
    R4 --> R5["For each candidate:\nSMTP verify\n(MX + RCPT)"]

    R5 --> R6{"Any deliverable?"}
    R6 -->|"Yes"| R7["Cache in contacts\n[source=pattern,\nstatus=deliverable]"]
    R7 --> RET

    R6 -->|"No"| R8["Apollo API\n(fallback)"]
    R8 --> R9{"Apollo returned\nemail?"}
    R9 -->|"Yes"| R10["Verify Apollo email"]
    R10 --> R11["Cache in contacts\n[source=apollo]"]
    R11 --> RET

    R9 -->|"No"| ERR["Return\nemail_not_found"]
